# brayanvillatoro.github.io
Personal website, served by GitHub Pages at https://www.brayanvillatoro.com.

Static HTML at the repo root; `media/` holds images and video.

Rebuild Tailwind after changing classes in any page or `script.js`:

```
npx tailwindcss@3 -c tailwind.config.js -i tailwind-src.css -o tailwind.css --minify
```
